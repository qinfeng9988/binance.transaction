## 修改需求

### 需求: 系统必须验证配置文件格式
系统必须在加载配置时校验 YAML 结构与字段类型，且必须校验所有声明的交易周期均存在于周期注册表中；任一周期非法时拒绝加载并输出明确的错误提示。

#### 场景: 配置周期通过校验
- **当** `strategies.yaml` 中所有策略 timeframes 均存在于周期注册表
- **那么** 系统正常加载配置

#### 场景: 配置周期非法
- **当** `strategies.yaml` 中某策略 timeframes 含注册表之外的周期
- **那么** 系统输出错误信息并拒绝加载

#### 场景: 手动配置周期校验
- **当** `manual_config.yaml` 的查询周期含注册表之外的周期
- **那么** 系统输出错误信息并拒绝使用该周期
