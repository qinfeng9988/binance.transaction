## 新增需求

### 需求:系统必须支持从 Binance 下载历史 K 线数据
系统必须能够从 Binance API 下载指定币种、timeframe 和历史范围的数据并存储到 PostgreSQL。

#### 场景:下载指定范围 K 线
- **当** 用户请求下载 BTCUSDT 1h 级别的 2025-01-01 到 2025-06-01 的数据
- **那么** 系统通过 ccxt 分页获取数据并存入 klines 表

#### 场景:增量更新
- **当** 系统需要获取最新 K 线数据
- **那么** 系统查询本地最新时间戳，仅拉取该时间之后的数据

### 需求:系统必须支持策略回测
系统必须使用 backtesting.py 框架对策略进行历史数据回测并生成绩效报告。

#### 场景:单策略回测
- **当** 用户对 support_resistance 策略运行回测
- **那么** 系统返回收益率、最大回撤、夏普比率、胜率、盈亏比

#### 场景:参数优化
- **当** 用户指定参数范围进行优化
- **那么** 系统执行网格搜索并返回最优参数组合

### 需求:系统必须支持回测数据可视化导出
系统必须将回测结果输出为可读的报告格式，包含交易明细和性能指标。

#### 场景:生成回测报告
- **当** 回测完成
- **那么** 系统输出包含关键指标和交易明细的文本报告
