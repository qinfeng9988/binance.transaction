## ADDED Requirements

### 需求:止盈目标计算
系统必须基于 S/R 位质量分为持仓模式计算持仓止盈目标（TP1/TP2）。做多时从高于当前价的阻力位中按 quality_score 降序选取，做空时从低于当前价的支撑位中按 quality_score 降序选取。

#### 场景:做多有足够阻力位
- **当** 持仓方向为 long 且高于当前价的阻力位 >= 2 个
- **那么** TP1 为质量分最高的阻力位价格，TP2 为质量分第二高的阻力位价格

#### 场景:做多只有1个阻力位
- **当** 持仓方向为 long 且高于当前价的阻力位 = 1 个
- **那么** TP1 为该阻力位价格，TP2 为 entry + 3×ATR

#### 场景:做多无阻力位
- **当** 持仓方向为 long 且高于当前价的阻力位 = 0 个
- **那么** TP1 为 entry + 2×ATR，TP2 为 entry + 3×ATR

#### 场景:做空有足够支撑位
- **当** 持仓方向为 short 且低于当前价的支撑位 >= 2 个
- **那么** TP1 为质量分最高的支撑位价格，TP2 为质量分第二高的支撑位价格

#### 场景:做空只有1个支撑位
- **当** 持仓方向为 short 且低于当前价的支撑位 = 1 个
- **那么** TP1 为该支撑位价格，TP2 为 entry - 3×ATR

#### 场景:做空无支撑位
- **当** 持仓方向为 short 且低于当前价的支撑位 = 0 个
- **那么** TP1 为 entry - 2×ATR，TP2 为 entry - 3×ATR

### 需求:止盈来源标记
系统必须为每个止盈目标标记来源（"sr" 表示来自 S/R 位，"atr" 表示来自 ATR 备选计算），并附带 S/R 位的质量分（仅 sr 来源时）。

#### 场景:止盈来自S/R位
- **当** TP1 价格取自某个阻力/支撑位
- **那么** tp1_source 为 "sr"，tp1_quality 为该位的 quality_score

#### 场景:止盈来自ATR备选
- **当** TP1 价格由 ATR 倍数计算得出
- **那么** tp1_source 为 "atr"，tp1_quality 为 None
