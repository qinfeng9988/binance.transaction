## MODIFIED Requirements

### 需求:持仓监控输出格式
系统必须按以下格式输出持仓监控结果，包含入场信息、盈亏、趋势、结构化建议（止损+止盈）和最近 S/R 位详情。

#### 场景:完整持仓监控输出
- **当** 持仓监控模式查询返回结果
- **那么** 输出格式必须包含以下区块：
  1. 标题行：`=== {symbol} {timeframe} 持仓监控模式 ===`
  2. 价格行：当前价格
  3. 入场行：入场价格和方向
  4. 盈亏行：浮动盈亏百分比和绝对金额
  5. 趋势行：趋势偏向、ADX、RSI
  6. 结构化建议区块：推荐止损（含距离百分比）、推荐止盈 TP1/TP2（含距离百分比和来源）
  7. 最近高质量支撑位列表（含质量分和中文标签）
  8. 最近高质量阻力位列表（含质量分和中文标签）

### 需求:S/R位标签中文翻译
系统必须将 vp_detail 字段翻译为中文显示，映射关系：POC_near→POC近区, POC_far→POC远区, HVN_near→HVN近区, HVN_far→HVN远区, VAH_near→VAH近区, VAL_near→VAL近区, VA_inner→Value Area内, LVN→LVN, none→不显示。

#### 场景:支撑位显示中文标签
- **当** 支撑位的 vp_detail 为 "POC_near"
- **那么** 输出显示为 "POC近区"

#### 场景:vp_detail为none时不显示标签
- **当** S/R 位的 vp_detail 为 "none"
- **那么** 输出中不显示标签部分
