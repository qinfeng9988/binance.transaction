## 新增需求

### 需求:系统必须提供标准技术指标计算能力
系统必须封装 TA-Lib（或 pandas-ta 备选），提供 RSI、EMA、MACD、布林带等标准指标计算。

#### 场景:计算 RSI
- **当** 策略请求计算 14 周期 RSI
- **那么** 系统返回基于收盘价序列的 RSI 值数组

#### 场景:计算 EMA
- **当** 策略请求计算 21 周期 EMA
- **那么** 系统返回基于收盘价序列的 EMA 值数组

### 需求:系统必须识别支撑位和压力位
系统必须提供基于历史 K 线的支撑位/压力位自动识别算法。

#### 场景:历史高低点识别
- **当** 系统分析一段 K 线历史数据
- **那么** 系统识别并返回聚类后的支撑位和压力位价格列表

#### 场景:支撑压力位附带强度
- **当** 系统返回支撑位/压力位
- **那么** 每个价位必须附带强度评分（基于触碰次数和成交量）

### 需求:系统必须计算成交量分布
系统必须支持 Volume Profile 计算，识别高成交量区域作为强支撑/压力。

#### 场景:计算成交量分布
- **当** 系统传入一段 K 线数据
- **那么** 系统按价格区间聚合成交量并返回高量节点
