## 新增需求

### 需求:系统必须支持 YAML 格式的配置文件
系统必须使用 YAML 格式管理所有配置，包含 exchanges.yaml、strategies.yaml 和 risk.yaml 三个核心文件。

#### 场景:加载 exchanges.yaml
- **当** 系统启动
- **那么** 系统读取 exchanges.yaml 获取 API Key、Secret 和数据库连接信息

#### 场景:加载 strategies.yaml
- **当** 系统启动
- **那么** 系统读取 strategies.yaml 获取策略列表、timeframe、币种和运行模式

### 需求:系统必须支持动态配置热重载
系统必须监听 strategies.yaml 和 risk.yaml 的文件变更，自动重新加载配置而不中断正在运行的策略。

#### 场景:策略参数热重载
- **当** 用户修改 strategies.yaml 中的止损百分比
- **那么** 系统在 5 秒内检测到文件变更并应用新参数

#### 场景:热重载不影响现有持仓
- **当** 配置热重载发生时存在活跃持仓
- **那么** 现有持仓不受影响，新信号使用新参数

### 需求:系统必须支持紧急暂停
系统必须通过检测 .pause 文件的存在来实现紧急交易暂停功能。

#### 场景:紧急暂停
- **当** .pause 文件被创建
- **那么** 系统立即停止所有新下单操作（含 paper 和 live 模式）

#### 场景:恢复交易
- **当** .pause 文件被删除
- **那么** 系统恢复策略调度

### 需求:系统必须验证配置文件格式
系统必须在加载配置时校验 YAML 结构和字段类型，且必须校验所有声明的交易周期均存在于周期注册表中；任一周期非法时拒绝加载并输出明确的错误提示。

#### 场景:配置校验失败
- **当** strategies.yaml 中缺少必要的 strategy name 字段
- **那么** 系统输出错误信息并拒绝启动

#### 场景:杠杆值越界
- **当** risk.yaml 中主流币杠杆配置为 10x
- **那么** 系统发出警告并将杠杆限制为 5x

#### 场景:配置周期通过校验
- **当** strategies.yaml 中所有策略 timeframes 均存在于周期注册表
- **那么** 系统正常加载配置

#### 场景:配置周期非法
- **当** strategies.yaml 中某策略 timeframes 含注册表之外的周期
- **那么** 系统输出错误信息并拒绝加载

#### 场景:手动配置周期校验
- **当** manual_config.yaml 的查询周期含注册表之外的周期
- **那么** 系统输出错误信息并拒绝使用该周期
