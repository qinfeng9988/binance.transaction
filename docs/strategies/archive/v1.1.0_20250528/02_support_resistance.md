# 支撑/阻力位多周期趋势确认策略

| 属性 | 值 |
|------|-----|
| 策略名称 | `support_resistance` |
| 策略类型 | 趋势跟踪 + 技术分析 |
| 核心思想 | 在高质量支撑/阻力位附近，经多维度过滤（ADX/RSI/成交量/拒绝蜡烛/回踩）确认后，顺势交易为主、逆势交易为辅 |
| 适用市场 | 高流动性、有明确趋势或区间震荡的加密货币市场 |
| 交易标的 | BTC/USDT, ETH/USDT, SOL/USDT, PAXG/USDT |
| 时间周期 | 5m, 1h, 4h（多周期联动） |
| 当前版本 | v1.1.0 |

## 1. 核心算法

### 1.1 支撑/阻力位识别（质量加权版）

采用三层算法 + 加权评分融合：

```
[波段高低点检测] → [价格聚类] → [成交量分布确认] → [质量加权评分]
```

#### 波段高低点检测（Swing High/Low）
- 对于每根 K 线，比较其左右各 N 根 K 线
- 低点低于左右所有低点 → 波段低点（潜在支撑）
- 高点高于左右所有高点 → 波段高点（潜在压力）
- 默认参数：`left=2, right=2`

#### 价格聚类与密度
- 将波段高低点按价格聚类（容差 0.5%）
- **聚类密度加成**：0.5% 容差内的价格点越多，`density_bonus` 越高（`density × 0.3`，上限 2.0）

#### 成交量分布确认（Volume Profile）
- 将 K 线数据分成 50 个价格区间
- 高成交量节点附近的 S/R 位强度 +1

#### 质量加权评分

每个 S/R 位的最终质量分数：

```
quality_score = strength + vp_bonus + vol_surge_bonus + density_bonus
```

| 加分项 | 条件 | 分值 |
|--------|------|------|
| 基础强度 | 聚类触碰次数 | `strength` |
| 成交量分布 | 位于高成交量节点 ±1% 内 | +1 |
| 成交量爆发 | 最新 K 线量 ≥ 1.5× 前20平均 | +1 |
| 聚类密度 | 0.5% 容差内点数 × 0.3 | 最高 +2.0 |

#### 拒绝蜡烛确认（Rejection Candle）

| 方向 | 条件 | 说明 |
|------|------|------|
| 多头 | 长下影线 ≥ 实体 2 倍 + 收盘价 > 开盘价 | 在支撑位附近出现 |
| 空头 | 长上影线 ≥ 实体 2 倍 + 收盘价 < 开盘价 | 在压力位附近出现 |

- 检查最近 5 根 K 线中是否有拒绝蜡烛
- 若 `require_rejection_candle=true` 但未找到，质量分乘以 0.3

**实现位置：** `quant_trader/technical/support_resistance.py`

### 1.2 趋势判断（双 EMA 交叉）

| 参数 | 值 | 说明 |
|------|-----|------|
| 快线周期 | 21 | EMA(21) |
| 慢线周期 | 50 | EMA(50) |
| 震荡阈值 | 0.3% | 两线间距 < 0.3% 视为震荡 |

**判断逻辑：**
- `EMA(21) > EMA(50)` 且间距 ≥ 0.3% → **上涨趋势 (uptrend)**
- `EMA(21) < EMA(50)` 且间距 < 0.3% → **下跌趋势 (downtrend)**
- 间距 < 0.3% → **震荡 (ranging)**

**实现位置：** `quant_trader/strategies/s_r_levels.py:detect_trend()`

### 1.3 上级周期 EMA 锚定

新增 v1.1.0：仅当上级周期 EMA21/50 同向时，才允许下级周期交易。

| 当前周期 | 上级周期（parent） | 锚定检查 |
|---------|-------------------|---------|
| 1h | 4h | 4h EMA 同向才允许 1h 信号 |
| 5m | 1h | 1h EMA 同向才允许 5m 信号 |
| 4h | 1d | 1d EMA 同向才允许 4h 信号 |

> **注意**：5m 周期目前通过 1h 锚定（parent）。如需真正的 4h 锚定，需修改 `main.py` 传递 4h 数据。

若上级 EMA 不同向，策略返回 `bias=neutral`（不交易）。

**实现位置：** `quant_trader/strategies/s_r_levels.py:detect_trend_with_parent()`

### 1.4 ADX 趋势强度过滤

| 参数 | 值 | 说明 |
|------|-----|------|
| ADX 周期 | 14 | ADX(14) |
| 最低 ADX | 22 | ADX < 22 视为弱趋势/震荡，跳过 |

**逻辑：** 在生成任何信号前，先检查当前周期 ADX。ADX < 22 时直接返回空列表，不生成任何信号。

**实现位置：** `quant_trader/strategies/s_r_levels.py:check_adx_strength()`

## 2. 交易逻辑

### 2.1 信号生成流程（v1.1.0 完整版）

```
获取 K 线数据
    ↓
1. ADX 趋势强度检查（ADX >= 22？）
    ↓ 否 → 返回空
2. 多周期趋势确认 → 得到 Bias（交易偏向）
    ↓
3. 上级周期 EMA 锚定检查
    ↓
4. 识别高质量支撑/压力位（加权评分）
    ↓
5. 确定各方向入场条件（主方向/副方向）
    ↓
6. 逐层过滤：
    ├── 6a. 价格 vs EMA21 位置过滤
    ├── 6b. RSI 动量过滤
    ├── 6c. 成交量爆发确认
    ├── 6d. 拒绝蜡烛确认（可选）
    └── 6e. 回踩/重新测试确认（可选）
    ↓
7. 计算 ATR 动态止损
    ↓
8. 生成 Signal
```

### 2.2 入场条件

#### 做多（Buy）

| 条件 | 主方向 | 副方向 |
|------|--------|--------|
| 最低质量分 | 3 | 4 |
| 入场距离阈值 | 0.5% | 0.3% |
| 价格 vs EMA21 | 价格 > EMA21 | 价格 > EMA21 |
| RSI(14) | 45 < RSI < 70 | RSI < 40 |
| 成交量爆发 | 量比 >= 1.8× | 量比 >= 1.8× |
| 拒绝蜡烛 | 可选（由参数控制） | 可选 |
| 回踩确认 | 近期有 K 线低点跌破支撑 | 近期有 K 线低点跌破支撑 |

#### 做空（Sell）

| 条件 | 主方向 | 副方向 |
|------|--------|--------|
| 最低质量分 | 3 | 4 |
| 入场距离阈值 | 0.5% | 0.3% |
| 价格 vs EMA21 | 价格 < EMA21 | 价格 < EMA21 |
| RSI(14) | 30 < RSI < 55 | RSI > 60 |
| 成交量爆发 | 量比 >= 1.8× | 量比 >= 1.8× |
| 拒绝蜡烛 | 可选 | 可选 |
| 回踩确认 | 近期有 K 线高点突破压力 | 近期有 K 线高点突破压力 |

### 2.3 止损设置（ATR 动态）

v1.1.0 新增 ATR 动态止损，替代固定百分比：

```
止损距离 = ATR(14) × atr_multiplier（默认 1.5）

做多止损 = 入场价 - 止损距离
做空止损 = 入场价 + 止损距离
```

当 ATR 数据不足时，回退到固定百分比（`stop_loss_pct=1.5%`）。

| ATR 场景 | 止损行为 |
|---------|---------|
| 高波动（大 ATR） | 止损更宽，避免假突破扫损 |
| 低波动（小 ATR） | 止损更紧，优化盈亏比 |
| ATR 数据不足 | 回退到固定 1.5% |

**实现位置：** `quant_trader/strategies/s_r_levels.py:compute_dynamic_stop_loss()`

### 2.4 出场条件

| 类型 | 条件 | 说明 |
|------|------|------|
| 止损 | 价格触及 ATR 动态止损位 | 由策略生成信号时设定，引擎自动监控 |
| 反向信号 | 持有多仓时收到 sell / 持有空仓时收到 buy | 先平仓再反向开仓 |
| 同向加仓 | 同方向新信号 | 以新价格加仓，更新持仓均价 |

**实现位置：** `quant_trader/exchange/paper_trading.py`

## 3. 策略参数

```yaml
# quant_trader/config/strategies.yaml

params:
  # ========== S/R 检测参数 ==========
  lookback: 100                    # S/R 识别回看 K 线数
  min_touches: 3                   # 主方向最低质量分（v1.1: 加权评分）
  stop_loss_pct: 1.5               # 备用固定止损（%）
  leverage: 5                      # 杠杆倍数（会被风控限制）
  entry_threshold_pct: 0.5         # 主方向入场距离阈值（%）
  secondary_min_touches: 4         # 副方向最低质量分（更严格）
  secondary_entry_threshold_pct: 0.3  # 副方向入场距离阈值（%）

  # ========== 趋势过滤参数 ==========
  require_parent_ema_aligned: true # 上级 EMA 同向锚定开关
  adx_period: 14                   # ADX 计算周期
  adx_min: 22.0                    # 最低 ADX 阈值
  price_vs_ema_filter: true        # 价格 vs EMA21 位置过滤开关

  # ========== 动量/波动参数 ==========
  rsi_period: 14                   # RSI 计算周期
  rsi_long_min: 45.0               # 主方向做多 RSI 下限
  rsi_long_max: 70.0               # 主方向做多 RSI 上限
  rsi_short_min: 30.0              # 主方向做空 RSI 下限
  rsi_short_max: 55.0              # 主方向做空 RSI 上限
  rsi_countertrend_long_max: 40.0  # 逆势做多 RSI 上限（超卖）
  rsi_countertrend_short_min: 60.0 # 逆势做空 RSI 下限（超买）
  volume_burst_ratio: 1.8          # 成交量爆发倍数
  volume_burst_lookback: 20        # 成交量平均回看周期

  # ========== ATR 动态止损 ==========
  use_atr_stop: true               # 使用 ATR 动态止损
  atr_period: 14                   # ATR 计算周期
  atr_multiplier: 1.5              # ATR 止损倍数

  # ========== 拒绝蜡烛 ==========
  require_rejection_candle: false  # 是否要求拒绝蜡烛（保守可开）

  # ========== 回踩确认 ==========
  require_pullback_retest: true    # 是否要求回踩确认
  pullback_lookback: 10            # 回踩检查回看周期
```

### 参数调优指南

| 参数名 | 默认值 | 取值范围 | 调优方向 |
|--------|--------|---------|---------|
| `lookback` | 100 | 50-500 | 增加 → 识别更长期 S/R，减少噪音 |
| `min_touches` | 3 | 2-6 | 增加 → 更高质量信号，但数量减少 |
| `entry_threshold_pct` | 0.5 | 0.1-1.0 | 增加 → 更早入场，但可能错过最佳位置 |
| `adx_min` | 22 | 15-30 | 增加 → 更严格（只交易强趋势），信号更少 |
| `rsi_long_min/max` | 45/70 | 30-80 | 缩窄 → 更严格，避免追单 |
| `volume_burst_ratio` | 1.8 | 1.2-3.0 | 增加 → 只在大成交量时入场 |
| `atr_multiplier` | 1.5 | 1.0-3.0 | 增加 → 更宽止损，减少假突破扫损 |
| `require_rejection_candle` | false | true/false | 设为 true → 信号大幅减少，但胜率提升 |
| `require_pullback_retest` | true | true/false | 设为 false → 信号增加，但回踩确认丢失 |

## 5. 信号模型

```python
Signal(
    strategy_name="support_resistance",
    symbol="BTC/USDT",
    timeframe="5m",
    signal_type="buy",           # "buy" | "sell"
    price=65000.0,               # 当前价格（触发信号时的价格）
    stop_loss=63975.0,           # 止损价格（ATR 动态计算）
    leverage=5,
    metadata={
        "support_level": 65000.0,           # 支撑位价格
        "support_strength": 3,              # 基础触碰次数
        "quality_score": 4.5,               # 质量加权评分
        "distance_to_support_pct": 0.3,     # 现价与支撑位的距离（%）
        "trend": "uptrend",                  # 当前周期趋势
        "parent_trend": "uptrend",           # 上级周期趋势
        "parent_aligned": True,              # 上级 EMA 是否同向
        "bias": "long_only",                 # 交易偏向
        "is_primary": True,                 # 是否为主方向
        "adx": 28.5,                         # ADX(14) 当前值
        "rsi": 52.3,                         # RSI(14) 当前值
        "volume_ratio": 2.1,                 # 当前量/20均量比值
        "has_rejection": True,               # 是否有拒绝蜡烛
        "stop_loss_type": "atr",             # "atr" | "fixed"
    }
)
```

## 6. 执行流程

### 6.1 引擎调度

```
main.py 引擎
    ├── 并发运行 (strategy, symbol, timeframe) 组合
    │     └── 每个组合独立循环：
    │           1. 拉取 K 线 → 存入数据库
    │           2. 获取上级周期 K 线（缓存）
    │           3. 调用 strategy.on_bar(klines, parent_klines)
    │           4. 策略内部处理：
    │              ├── ADX 检查
    │              ├── 多周期趋势确认
    │              ├── S/R 识别（质量评分）
    │              ├── 逐层过滤（RSI/成交量/拒绝蜡烛/回踩）
    │              └── 信号生成
    │           5. 信号去重（300秒冷却）
    │           6. 风控检查
    │           7. 执行交易（模拟/实盘确认/实盘自动）
    │           8. 休眠至下一周期
    └── 每 10 个周期打印账户概览
```

### 6.2 错开启动机制

为避免多个周期在同一时刻对同一币种发单冲突：
- 各周期首次启动随机延迟 1-5 秒
- 多任务间额外错开 2-8 秒
