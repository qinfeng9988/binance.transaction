## 1. 策略概述

PAXG（Paxos Gold）是锚定黄金的加密货币，波动极小（日内波动通常 < 0.5%）。传统 S/R 策略在此类品种上效果不佳，因此采用更简单的双均线交叉趋势跟踪策略。

## 2. 交易逻辑

### 2.1 数据输入

| 输入 | 说明 | 来源 |
|------|------|------|
| OHLCV | 1h K 线数据 | Binance API |

### 2.2 信号生成流程

```
获取 1h K 线数据
    ↓
计算 EMA20 / EMA50
    ↓
判断均线交叉（金叉/死叉）
    ↓
RSI 过滤极端情况
    ↓
生成开仓/平仓信号
```

### 2.3 入场条件

#### 做多（Buy）
1. EMA20 上穿 EMA50（金叉）
2. RSI < 75（不过度超买）

#### 做空（Sell）
1. EMA20 下穿 EMA50（死叉）
2. RSI > 25（不过度超卖）

### 2.4 出场条件

| 类型 | 条件 | 说明 |
|------|------|------|
| 止损 | 价格触及 ATR(14) × 1.5 | ATR 动态止损 |
| 反向信号 | 均线反向交叉 | 先平仓再反向开仓 |

## 3. 策略参数

```yaml
- name: bollinger_bands_paxg
  enabled: false  # 2026-09-13 废弃，替换为 S/R 策略
  symbols:
  - PAXG/USDT
  timeframes:
  - 1h
  params:
    # 双均线参数
    ema_fast_period: 20
    ema_slow_period: 50
    # RSI 参数
    rsi_period: 14
    rsi_overbought: 75
    rsi_oversold: 25
    # ATR 止损
    atr_period: 14
    atr_multiplier: 1.5
    # 杠杆
    leverage: 3
```

## 4. 风控集成

| 风控项 | 策略内实现 | 外部风控接管 | 说明 |
|--------|-----------|-------------|------|
| ATR 止损 | **是** | 检查 | 策略设定止损距离 |
| 杠杆 | 建议值 | **限制** | 策略请求 3x，风控按币种上限调整 |
| RSI 过滤 | **是** | 否 | 避免极端情况入场 |

## 5. 信号模型

```python
Signal(
    strategy_name="bollinger_bands_paxg",
    symbol="PAXG/USDT",
    timeframe="1h",
    signal_type="buy|sell",
    price=current_price,
    stop_loss=entry_price ± atr * multiplier,
    leverage=3,
    metadata={
        "fast": current_fast,
        "slow": current_slow,
        "rsi": current_rsi,
        "atr": current_atr,
    }
)
```

## 7. 策略演进

### 尝试过的策略变体

| 策略类型 | 回测结果 | 结论 |
|---------|---------|------|
| 布林带均值回归 (2σ) | -4.01% | 假突破频繁，亏损 |
| 布林带均值回归 (3σ) | -0.70% | 信号太少，盈亏平衡 |
| 布林带趋势突破 | -6.19% | 波动太小，突破无效 |
| 布林带挤压突破 | -1.03% | 收缩后扩张信号少 |
| **双均线交叉 (EMA20/50)** | **+1.57%** | **最优方案** |

### 关键优化点

1. **周期选择**：5m 周期交易 367 次，亏损 -4%；1h 周期交易 49 次，盈利 +1.57%
2. **均线周期**：EMA9/21 交易 38 次，亏损 -1.3%；EMA20/50 交易 23 次，盈利 +0.52%
3. **杠杆调整**：2x 杠杆收益 +0.52%，3x 杠杆收益 +1.11%
