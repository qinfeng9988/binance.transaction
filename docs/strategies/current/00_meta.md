## v1.1.0 变更摘要

### A. S/R 位质量过滤
- **质量加权评分**：触碰次数 + 成交量爆发(>1.5x) + 聚类密度(0.5%容差内点数) 综合评分
- **拒绝蜡烛确认**：支撑位长下影线(≥实体2倍)+收阳 / 压力位长上影线+收阴
- **最低质量分阈值**：主方向≥3，副方向≥4（v1.0.0为固定触碰次数）

### B. EMA + 趋势过滤
- **上级周期 EMA 锚定**：`require_parent_ema_aligned=true` 时，仅当上级周期 EMA21/50 同向才允许交易
- **ADX(14) 趋势强度过滤**：ADX < 22 视为震荡，直接跳过
- **价格 vs EMA21 位置过滤**：做多要求价格 > EMA21，做空要求价格 < EMA21

### C. 动量/波动过滤
- **RSI(14) 动量过滤**：
  - 主方向做多：45 < RSI < 70（健康区间）
  - 主方向做空：30 < RSI < 55
  - 逆势做多：RSI < 40（超卖反弹）
  - 逆势做空：RSI > 60（超买回落）
- **成交量爆发确认**：当前量 > 前20平均 × 1.8
- **ATR(14) 动态止损**：止损距离 = ATR × 1.5（替代固定1.5%）

### D. 入场优化
- **回踩/重新测试确认**：突破 S/R 后等待价格回踩该位再入场
- **参数全部可配置**：所有新过滤器均可通过 `strategies.yaml` 开关和调参
